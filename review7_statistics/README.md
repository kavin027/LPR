# Statistics for the revised registration comparison

From an extracted release, run:

    python review7_statistics/statistics.py . reproduced-statistics

The script needs pandas, NumPy and threadpoolctl. It uses archived request masks, group IDs and previously recorded fit diagnostics. It uses no new model calls, training examples or test-set selection. Cohorts are called cn (CrossWOZ), spider (development) and confirmation (the additional eight Spider databases). New comparisons on the last cohort are retrospective. Percentages in these tables run from 0 to 100.

## Registry selection

* original_selector.csv compares hybrid to fixed full inverse, fixed count with unit weight and selected count with a registry-only choice of count weight. Each row reports both hit counts, hybrid's fixes and harms, and a 95% cluster percentile interval. For the indicated population, resample its whole query groups with replacement, preserving all requests in each sampled group. Use 2,000 multinomial multiplicity draws with seed 251121. Group ordering follows the released fixed-registry checker (numeric dialogue IDs where applicable; otherwise lexicographic IDs).
* crossed_selector.csv compares the same three references on the ten registries in each original regime. Each draw contributes its own request-weighted percentage, and draws receive equal weight. Following the earlier registry audit, resample the whole-query groups and the ten registry indices with replacement, sharing the query-group multiplicities among registries. Recompute each stratum denominator before averaging. The original archived order for the crossed simulation is lexical group ID, then lexical draw file name. The two bootstrap implementations have the same cluster unit and differ in ordering as described above to reproduce the respective archived conventions. All 2,000 bootstrap replicates are valid in every cell. Intervals condition on the observed pool, including overlap among draws. The [0,0] interval for the additional cohort's original unseen hybrid–full comparison results from identical paired correctness on every observed request.
* Fixed-registry CrossWOZ hybrid minus full is +3.94 percentage points [2.51,5.39] on all requests and −0.74 [−2.87,1.46] on unseen requests. Crossed unseen hybrid minus full, uniform then enriched: CrossWOZ −2.69 [−5.69,−0.12] and −1.11 [−2.85,0.50]; Spider +0.17 [−1.25,1.66] and −1.07 [−3.11,0.74]; additional +0.56 [−2.90,4.61] and −0.69 [−6.85,5.58]. All six recomputations reproduce the reviewer's values to two decimals.

## Fit and evaluation population

per_draw_crossed_population.csv evaluates each pair of fits on exactly the IDs supplied by either membership definition. Use each scoring fit's own label encoding for the prediction, gold and exact-match comparison. An atom unsupported by the scoring fit counts as an error even if the request is eligible under the other registry. The original unseen and all-request populations have fixed membership within a dataset. For redraw-defined unseen membership, both fits are evaluated on the same within-draw IDs. The ten enlarged/contracted populations need not be identical. The full vs fixed-count contrast within each fit uses that fit's forward model and candidates. The changing registry also changes vocabulary, forward scores and proposals. The comparisons do not isolate any single component of refitting.

crossed_population.csv averages each per-draw percentage and hit count with weight 1/10; a mean percentage need not equal the ratio of the two mean counts. Original-fit / original-membership results are repeated solely for a common table layout; these are not independent replications. All three cohorts and both uniform and enriched regimes are included. The crossed comparisons are descriptive and do not add up to two separate causal effects.

## Generality and numerical replay

breadth.csv and breadth_by_group_or_set.csv report the original unseen populations. Each distinct set has equal weight for macro accuracy; request accuracy weights all requests equally. The best-set and two highest database net counts are simple descriptive summaries selected *after* observing queried outcomes. Additional Spider has 59 unseen requests across 20 target sets and eight databases; the largest set occurs 16 times. Original Spider has 548 unseen requests across 79 sets and 35 databases. Full inverse hits 50/548 (9.12% request-weighted; 3.71% equal weight by target set). One set supplies 20 of the 34 net gains over fixed count. The two largest database net gains are four each. Net gains are positive in 20 databases, zero in ten and negative in five.

small_budget_ties.csv reads the earlier replay's label-equivalence diagnostics for the ten uniform CrossWOZ registries of size 25. Across three draws, 292 masks change within classes of mathematically indistinguishable labels. Relative to the same diagonal predictions, the ten-draw mean all-query full-minus-diagonal changes from −0.46 pp with archived masks to −0.26 pp on common-arithmetic replay. The 75-example comparisons did not require these replacements. fresh_encoder.csv aligns archived and freshly encoded plain Qwen by ID and checks each gold mask and stratum. On CrossWOZ full inverse, 29 masks change overall (six fixes, seven harms; −0.0364 pp); 13 masks change on the 1,223 unseen requests (two fixes, three harms; −0.0818 pp). Predictions may change without changing correctness.

# Same-encoder text head

This module fits a text-only revised-label ridge head on the frozen Qwen3-Embedding-0.6B features also used in Forward. Every arm scores the same candidates generated by the original Forward. Because this list depends on Forward, the Base row isolates the scoring head on a fixed opportunity set. It does not represent an end-to-end pipeline without legacy inputs. The head uses a centered kernel ridge fit with an unpenalized intercept and unit penalty, which gives identical predictions to the centered raw-vector solver.

Run `python -B matched/verify.py` from an extracted numerical archive containing matched/, primary/, interface/, decoder/ and cal/. Only NumPy and pandas are required. To keep this as a standalone supplement alongside the main artifact, run `python -B compact/verify.py --reference PATH_TO_MAIN_REPLAY`. inputs/ stores registry and query-by-registry dot products, registry revised labels, IDs and fold-local Forward logits. The verifier refits all twelve heads from these sufficient statistics, checks fold coordination and reconstructs all candidate choices. The summary includes original seen and supported-unseen strata, plus overall accuracy on every query (including unsupported targets).

Two scripts support an independent reconstruction from the complete numerical archive. `python -B full/build.py HISTORICAL_R81 NEW_INPUTS` rebuilds sufficient statistics from the raw cached embeddings. `python -B full/validate.py HISTORICAL_R81 compact` performs all ridge fits on raw features, regenerates the candidate lists, refits Forward and the pooled covariance and checks every registered grid prediction and every evaluation outcome against the compact record. Both checks reproduced the tabulated results exactly on these data.

CrossWOZ improved from 40.71% to 62.50% on all requests after adding the pooled inverse to Base + Forward, and from 18.64% to 50.29% on supported unseen combinations. SpiderOps improved from 16.52% to 21.96% on all requests and from 1.46% to 7.66% on unseen combinations. The simpler matched-encoder head had lower absolute accuracy than the primary DVLC configuration. The comparison isolates a change of base encoder/head in these original registries and does not reproduce DVLC using Qwen or establish robustness to arbitrary replacements.

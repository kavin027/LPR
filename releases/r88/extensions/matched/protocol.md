# Frozen same-encoder control

Original 75-register and grouped five folds per task; original primary registry, query IDs and strata. Substitute a distinct B-label head fitted solely from the Qwen3-Embedding-0.6B frozen text vectors used by the Forward decoder. Use the existing centered unit-penalty ridge with unpenalized intercept, register-fold clip [1/(n+2),1-1/(n+2)], and sum the target log odds over a proposed set for the class score E. All remaining components of the original comparison are fixed, including the original legacy-aware Forward scorer U, its K=5 proposal lists in original order, and the pooled inverse I. Score E, E+U, E+U+alpha I. E uses the shared candidate list, so proposal membership can carry historical information even though E is fitted solely on text. For each held-out registry fold, fit the head and all relevant statistical components strictly on the other groups and keep only B and registered A labels observed in those groups. Select alpha from (1,0.5,2,0.25,0) by pooled held-out exact hits; resolve ties by original weight order. Fix alpha before evaluating all independent query groups. Report same-encoder base scores, F/H and the conditional group-bootstrap interval of adding inverse to E+U; do not use test labels or select alternative head hyperparameters. This is a retrospective, matched-feature linear head control; it does not reproduce the DVLC architecture on another encoder.

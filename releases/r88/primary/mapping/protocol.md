# Common-base mapping and incremental inverse, retrospective protocol frozen before scoring

Use the original primary DVLC fit, original CrossWOZ and SpiderOps registry of 75 per task, existing five grouped folds, original candidate proposal generator (K=5), all original evaluation requests and stratum definitions, and the original pooled inverse. No protected set or neural model is used. For each fold, retain only A and B atoms present in its training registry. Fit a centered additive, intercept-unpenalized, unit-penalty ridge from human A labels to human B labels. At deployment, replace A indicators by their corresponding raw legacy scores where a historical output coordinate exists, filling unavailable coordinates with zero. Clip the resulting B probabilities to the original fold-specific interval and sum their log odds over atoms in each candidate. Mapping-only must reproduce the historical mapping decisions. Keep every unsupported target in all-request accuracy.

Keep the original Base + Forward unary as the common score J and use the positive inverse contribution I (minus the pooled squared discrepancy, up to candidate-constant terms), mapping score M, and log-smoothed registry label-count C. Use the original ordered grid (1, 0.5, 2, 0.25, 0), maximizing exact correct sets over all 75 grouped out-of-fold predictions; tie goes to the earlier listed value. Compare J; J+beta M (select beta); J+alpha I (independently select alpha as in the primary decoder); and J+beta M+gamma I (lock the first-stage beta and choose gamma on the same fold-out scores). As a two-weight control, start with exactly the same selected mapping and add an empirical count term J+beta M+eta C by the same procedure. No full 25-cell joint optimization, no evaluation-label selection. Grid zero disables the component. Each two-stage comparison estimates the effect after fitting the mapping on that registry and does not estimate out-of-sample calibration performance from the reused registration hits. Report accuracy, paired fixes and harms and grouped percentile intervals (2,000 paired cluster resamples, original seed 251121) for all and supported-unseen requests. These are retrospective, original-registry and primary-DVLC comparisons.

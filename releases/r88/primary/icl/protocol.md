# Candidate-constrained text-model controls

Both frozen Qwen3-4B (Q4_K_M) controls classify the same 4,711 requests on the same request-specific candidate lists as the DVLC-based decoder. The first prompt supplies all 75 registration examples in registry order and the target label names. The second prompt retrieves the five registration sentences with highest cosine similarity in the frozen embedding space (original index breaks ties) and supplies a study-authored glossary. Both use greedy non-thinking decoding with a grammar that restricts output to the offered candidate codes, with an allowance of 24 generated tokens. The compact replay uses frozen outputs and requires no language-model inference.

Both prompts have access to the registered examples. Candidate construction transmits information from the historical classifier indirectly, but neither prompt receives its raw score vector. The glossary gives the retrieved variant additional prior information. The paired comparison measures complete systems under common proposals, with different model architectures and inputs.

For each cached reply, the generated code was independently decoded to its predicted set and checked against both the saved mask and the original proposal list. Every output was legal. The bundled predictions retain the query ID and two decoded masks. Run python -B icl/verify_icl.py from the compact archive root to join those masks to the original registry-selected DVLC-based LPR outputs and full target records, verify list membership, and recompute paired.csv. Positive paired gain favors LPR. Grouped percentile intervals resample whole dialogues or databases under the original fixed-registry procedure.

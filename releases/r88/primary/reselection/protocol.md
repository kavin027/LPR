# Frozen registry-weight reselection protocol

Use all 40 previously specified 75-row standalone draws (10 uniform and 10 enriched per task). Reuse the archived group-isolated fivefold assignments for the 3,000 registration observations. Keep target and old annotation columns appearing in each training fold, derive candidates exclusively from that training fold and its fitted Forward scores, and score novel held-out atoms as errors. Use the previous exact-set objective and inherited tie order 1, 0.5, 2, 0.25, 0. Select one multiplier per arm (Full, Row, ECP) and draw. Record choices before processing any test data. Refit on the entire draw, keeping the same decoder feature implementation, candidate enumeration, score ties and query IDs. No new neural fits or random draw selection.

Report all requests, draw-relative supported unseen sets and the fixed original unseen cohort. The primary paired comparison is reselected Full versus independently reselected ECP. Compare reselected Full to Row, unit Full and transferred Full, and to matching fixed ECP and Row controls. Aggregate accuracies, paired gains and counts as means across draws and retain the per-draw ledger. The 20 registries per task reuse test requests and do not form independent replication samples. CPU timing is a single replay diagnostic.

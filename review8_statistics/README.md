# Crossed registration and population comparisons

From the extracted archive root, run

    python review8_statistics/statistics.py . rebuilt-cross

The script reads query IDs and cluster IDs from `controls` and the frozen predictions and registry-relative strata from `review5_selector/predictions`. It checks the recomputed cell rates against the previous `review7_statistics/crossed_population.csv`. It uses pandas, NumPy and threadpoolctl.

Each cell denotes the **fit** followed by the registry defining **unseen membership**, with O for the original registry and R for the current redraw. Each decoder is scored against its own fit's local gold encoding. A request in the evaluation membership whose atom is unsupported by the scoring fit counts in the denominator and scores zero for both methods. Full and fixed-count predictions always see the same proposal set within a fit. The four contrasts are RO minus OO (change the fit on the original population), RR minus OO (change both), RR minus OR (change the fit on the redraw population), and OR minus OO (change the population for the original fit).

* `cells.csv` contains full and fixed-count exact-set accuracies (percent), hits, fixes, harms, unseen population size and their paired accuracy difference (percentage points). Values are ten equally weighted registry-draw means. A mean accuracy need not equal the ratio of mean hits to mean population size. The OO cell is identical across the ten draws.
* `per_draw.csv` gives each of the four paired contrasts for each redraw, dataset and sampling design. Each contrast is a difference between two full-minus-count accuracy differences. `contrasts.csv` supplies their mean, positive/tied/negative draw counts and paired 95% percentile intervals.
* `transitions.csv` gives all nine ordered cells of the request-count table of original vs redraw membership for every draw. Read either direction by conditioning on the corresponding column(s). The three states denote an observed complete set, an unregistered set of supported atoms, and at least one unsupported atom. For example, across ten enriched Spider development redraws, the original 548 unseen requests include an average of 293.7 seen and 254.3 still unseen under the refit, while 178.2 originally seen requests enter the redraw unseen population on average. The two unsupported requests remain unsupported. Counts refer to the common query pool in each draw, so adding observations across draws repeats requests.

For the interval, resample whole query clusters (dialogues for CrossWOZ, databases for Spider) and registry indices independently with replacement. Use one shared cluster-multiplicity vector and one shared draw-multiplicity vector for every arm and cell within a bootstrap replicate. Recompute the request-weighted accuracy difference within each sampled draw and population, then average paired contrasts across the sampled draws. Use 2,000 replicates, NumPy seed 251121, lexical group order and lexical redraw filename order, matching the previous crossed resampling convention. All 2,000 replicates have nonempty selected populations in every comparison. Intervals condition on the observed overlapping registries and query clusters. The additional Spider cohort's redraw comparisons are retrospective.
